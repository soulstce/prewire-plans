# Prewire Plans

Prewire Plans is a dark, Apple-inspired PDF review workspace for plan markup and collaborative prewire planning.

## Features
- Dashboard, Projects, PDF Viewer, Upload, and Settings pages
- PDF rendering with zoom, page navigation, and pan via the scroll container
- Drawing layer for pen, line, arrow, rectangle, ellipse, text, eraser, undo, and redo
- Live markup sync across tabs using BroadcastChannel-backed room sync
- Responsive layout for mobile, tablet, and desktop

## Local development
```bash
npm install
npm run dev
```
